# Unemployment Analysis in India

## Project Overview
This project analyzes unemployment trends in India using Python, data analysis, and visualization techniques.

## Objective
To explore unemployment patterns across Indian states, understand changes over time, and compare unemployment rates before and during the COVID-19 period.

## Dataset
- Dataset: Unemployment in India
- File: `Unemployment_Rate_upto_11_2020.csv`
- Important columns:
  - Region
  - Date
  - Estimated Unemployment Rate (%)
  - Estimated Employed
  - Estimated Labour Participation Rate (%)

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow
1. Imported the required Python libraries.
2. Loaded and explored the dataset.
3. Checked missing values and duplicate records.
4. Cleaned the dataset.
5. Analyzed overall unemployment statistics.
6. Compared average unemployment rates across states.
7. Identified the top 10 states with the highest average unemployment.
8. Visualized unemployment trends over time.
